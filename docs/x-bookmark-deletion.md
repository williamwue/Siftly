# 同步删除 X 书签

在 Browse 页面单条或批量删除时，勾选「同时取消 X 收藏」，填写 X 用户名并确认。默认仅删除本地数据。

需要本机安装并登录 Ego 浏览器，`ego-browser` 可从服务端 PATH 执行。服务须从项目根目录启动，保留 Node.js、tsx 和 scripts 目录。这是本地自托管功能，不适用于无浏览器的 serverless 部署。可用 SIFTLY_EGO_BINARY 指定 CLI 绝对路径。

任务持久化在 DATABASE_URL 对应的 SQLite 数据库。程序核对当前登录账号，定位指定推文的收藏按钮，取消后刷新页面重新验证。已取消的收藏也会重新验证。验证通过后才删除本地记录、媒体关联、分类关联和搜索条目，不删除原推文。

Browse 显示未完成任务及错误。失败项保留本地记录，可点击「重试」。进程中断超过 90 秒后标记失败，不直接删除本地数据。重新打开 Browse 会继续派发已授权的排队任务。账号填写错误时，可再次选择本地书签，在删除对话框修改用户名后提交。

本地和同步删除均写入 DeletedBookmark 排除表；文件、bookmarklet、cookie、OAuth 和实时导入路径会跳过这些推文。排除表随数据库备份保存。外部直接写 SQLite 的脚本需自行遵守这张表。

测试使用隔离数据库与模拟浏览器结果，不自动取消真实账号的收藏。
